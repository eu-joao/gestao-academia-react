## Desenvolvimento

Na raiz do repositório, use:

```bash
mise install
mise run install
mise run dev:web
```

A aplicação estará disponível em [http://localhost:3000](http://localhost:3000).

Consulte o [README da raiz](../README.md) para a visão geral do projeto e os comandos compartilhados.
