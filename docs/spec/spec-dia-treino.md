# Spec Dia de Treino

## Requisitos Funcionais

- Organize os dias de cada programa de treino
- Consulte os dias de treino de um programa
- Apresente os dias na ordem definida para o programa

## Dados do Dia de Treino

- Associe cada dia a um programa de treino
- Cadastre o nome do dia
- Cadastre a ordem do dia no programa

## Regras de Negócio

- Carregue os dias como parte dos dados iniciais dos programas predefinidos
- Mantenha a ordem dos dias dentro do programa
- Apresente os dias em sequência
- Após o último dia, reinicie a sequência pelo primeiro
- Não disponibilize criação ou edição de dias pelo personal na primeira versão

## Critérios de Aceitação

- Consulte os dias vinculados ao programa atual do aluno
- Apresente os dias na ordem definida
- Determine o próximo dia considerando as sessões concluídas do programa atual
- Reinicie a sequência após o último dia

## Interfaces

- Exiba os dias do programa atual no aplicativo mobile
- Destaque o próximo dia previsto para o aluno
